Weather Dashboard

Real-Time Weather Forecasting Tool

Project Overview

An interactive weather application using the OpenWeather API. Displays current weather, 5-day forecast, and historical trends with visually appealing charts and clean design.

Technologies Used

  • JavaScript (ES6)
  • OpenWeather API
  • Chart.js for data visualization
  • Async/Await for API calls
  • Responsive layout with CSS Flex/Grid
