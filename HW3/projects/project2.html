Task Management App

Real-Time Productivity Platform

Project Overview

A productivity application built with Vue.js and Firebase. It features drag-and-drop task management, team collaboration, and real-time syncing across users for efficient workflow handling.

Technologies Used

  • Vue.js (Composition API)
  • Firebase Authentication + Firestore
  • Tailwind CSS
  • VueDraggable for drag-and-drop
  • Real-time updates via Firestore listeners
