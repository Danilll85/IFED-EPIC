E-commerce Platform

Full-stack E-commerce Solution

Project Overview

A modern e-commerce platform built with React, Redux, and Node.js. The platform includes product listings, search and filtering, shopping cart functionality, user authentication, and secure checkout process with Stripe integration.

Technologies Used

  • React (Functional Components + Hooks)
  • Redux for state management
  • Node.js + Express backend
  • MongoDB with Mongoose
  • Stripe API for payments
  • JWT for authentication
